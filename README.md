# Siklab-kumpas — website & releases

Public site and download for **Siklab-kumpas**, a bi-directional Filipino Sign Language ↔ speech app (thesis project).

- Site: static HTML, deployed on Vercel from this repo.
- APK: attached to the [latest release](https://github.com/Dan-sama1/siklab-kumpas-web/releases/latest) as `siklab-kumpas.apk`.

The app's source lives in a separate repository.
